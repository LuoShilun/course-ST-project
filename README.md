# course-ST-project

## 项目简介

本项目为软件测试课程实践项目，主要围绕 Web 系统开展功能测试、接口测试、自动化测试等测试工作。

仓库主要包括被测系统源码、模块一测试内容以及模块二（ai测）测试内容。

## 项目目录

course-ST-project/
├── module1/       # 模块一测试内容
├── module2/       # 模块二测试内容
├── web_system/    # 被测 Web 系统
├── .gitignore
└── README.md

## 模块说明

### web_system

被测 Web 系统源代码，包括前端、后端以及相关配置文件。

### module1

模块一测试内容，包括测试用例、测试脚本、测试数据及测试结果等。

### module2

模块二测试内容，包括测试方案、测试脚本及相关测试结果。

## 运行环境

- Python
- Pytest
- Flask
- Vue
- MySQL

具体环境配置以 `web_system` 目录中的项目说明为准。

## 测试说明

本项目测试内容主要包括：

- 功能测试
- 接口测试
- 自动化测试
- 异常场景测试
- 回归测试
