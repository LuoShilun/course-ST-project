# 海巡智检 (OceanGuard AI) - 水下智能作业与资产管理系统

> 本文档为海巡智检系统的部署与操作规范指南。

## 1. 系统概述
海巡智检系统是一套为水下机器人 (ROV) 和固定探头设计的企业级污染监测解决方案。涵盖实时推理、多通道设备孪生、数字作业台账与自动报表装配。

## 2. 架构拓扑
- **前端控制台:** Vue 3 + TypeScript + Element Plus (全暗黑自适应风格)
- **算法算力层:** 基础清水识别 (YOLO 管道) + 浑水画质增强推理 (CycleGAN 管道)
- **信令管理后端:** FastAPI (Python) 异步任务队列

## 3. 功能矩阵
- 监控大盘: 流水与高危污染概略图 (Dashboard)
- 检测台: 图片/视频流侦测、前后置增强对比、置信度阈值热调
- 资产台账: 异常帧定格溯源、人工补偿纠偏入库、PDF安全水印巡检报告
- 孪生管理: 终端鉴权、信标绑定与 RBAC 权限下发
